# OFFGOTCHI Battle Pet Game (OFFZONE 2026)

Тамагочи-аддон на ESP32-C3 для конференции OFFZONE 2026: Выбираешь себе кубика-питомца, кормишь, качаешь уровни, эволюционируешь на пятом и дерёшься с другими кубиками по BLE прямо на конфе.
